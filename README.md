# PlatformIO Tutorial

ESP32 microcontroller project using PlatformIO and the Arduino framework.

## Setup

Install [PlatformIO](https://platformio.org/) (standalone or as a VS Code extension).

## Usage

```bash
pio run                    # Build
pio run --target upload    # Upload to ESP32
pio device monitor         # Serial monitor
pio test                   # Run tests
```

## Tech Stack

- C++ (Arduino framework)
- ESP32
- PlatformIO
- Unity (testing)
